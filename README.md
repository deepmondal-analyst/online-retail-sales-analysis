# Online Retail Sales Analysis

An exploratory data analysis project using the Online Retail II dataset to understand sales trends, product performance, and customer purchasing behaviour.

## Tools Used
- Python
- MySQL
- Power BI



## What I Did
- Analysed sales and cancelled transactions using SQL.
- Identified top-performing products by revenue and quantity.
- Analysed customer spending and repeat purchases.
- Explored monthly revenue trends.
- Built a Power BI dashboard to present the findings.

## Key Findings
- Total recorded revenue: 20.32M
- Non-cancelled orders: 45,336
- Average order value: 448.16
- Repeat customers: 4,255
- Top product by revenue: Regency Cake Stand
- Top product by quantity: White Hanging Heart T-Light Holder

##  Business Insights
- The Regency Cake Stand generated the highest sales value among the analysed products.
- The White Hanging Heart T-Light Holder sold the highest number of units.
- High sales volume does not necessarily translate into the highest revenue.
- November showed strong revenue performance in both 2010 and 2011.
- A substantial number of identifiable customers made repeat purchases.

## Dashboard

The Power BI dashboard includes sales KPIs, monthly revenue trends, top products, and top customers.
